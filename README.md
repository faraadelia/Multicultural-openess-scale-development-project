# Developing a Multicultural Openness Scale

Team project for PSYC 303 Data and Measurement, University of British Columbia.

We developed and validated a scale measuring university students' willingness to engage with cultures other than their own (n = 159).

## What the R script does
- Item analysis: descriptives, inter item correlations, item total correlations
- Reliability: Cronbach's alpha (.811) and McDonald's omega (.814)
- One factor exploratory factor analysis (SRMR = .045)
- Validity tests against two criterion questions

## Tools
R, psych, lavaan, semTools

Raw survey data is not shared to protect participant privacy.
